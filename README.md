# Document Parser

Document Parser

## Stack/Technology

[NestJs (Nodejs)] + [Typescript](https://www.typescriptlang.org/)

## Project Setup

```sh
npm install
```

### Start and Watch server

```sh
npm run start:dev
```

### Request

<p>
    In Postman set key to 'file', value is the PDF file. Send a POST request(form-data) to /parser endpoint 
</p>

### Set environment variable

```sh
cp .env.test .env

In .env file add
PORT=
```
